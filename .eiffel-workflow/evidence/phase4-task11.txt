LEFT  R2's hanging whitespace vs `layout''s `width_respected' - A GENUINE,
      NARROW CONTRACT TENSION, REPORTED RATHER THAN PAPERED OVER.
      LINE_LAYOUT_ENGINE.fits_within EXCLUDES a line-trailing whitespace RUN's
      advance from the fit test (that is what "hanging" means, and it is a
      contracted clause). SHAPED_LAYOUT.respects_width - which `layout' must
      ensure - measures the line's RAW width, trailing space included. So a line
      can fit by the engine's rule and still measure wider than the wrap width,
      exactly when the hang hangs.
      WHAT WAS DONE, without touching either contract:
        (a) `split_flags' never manufactures a whitespace-only run INSIDE an
            item - a break is never taken BEFORE a breaking space (UAX #14: the
            opportunity is after it, and a line must not start with the space it
            broke at), and never where it would close a sub-run of only spaces.
            That removes every case the facade owns.
        (b) `wrapped_lines' checks `lines_respect_width' after `build_lines' and,
            on a violation, re-wraps ONCE at a width reduced by
            `widest_whitespace_group' - the largest CONSECUTIVE whitespace-run
            advance, which is the engine's own upper bound on a line's trail
            (it resets the accumulator at the first ink run). That bounds every
            line's raw width by the ORIGINAL width.
      THE RESIDUAL: when a single whitespace group is itself as wide as the whole
      wrap width, no run partition `build_lines' can produce respects that width
      - a hang that large hangs past the margin by definition, and the engine
      never flags a solo whitespace run as overflowing (it "fits", its advance
      being excluded). Reaching it needs a whitespace-only ITEM or SEGMENT (the
      itemizer splitting spaces off by script or level, or text like emoji-space-
      emoji) AND a wrap width no wider than that run of spaces. Not reachable in
      the suite; not reachable in a chat bubble. NOT reconciled, NOT hidden.

LEFT  AC-7's "zero native calls" is true of the four SEAMS and not of font
